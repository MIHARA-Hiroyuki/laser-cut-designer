# レーザーカットデザイナー

レーザーカッターで加工するためのデータ(SVG)を、ブラウザだけで作成できる単一HTMLファイルの描画ツールです。インターネット接続や外部ライブラリ、インストール作業は一切不要で、ファイルを1つダウンロードして開くだけで使えます。学校のChromebookなど、管理が厳しい端末でも動作するように作られています。

**現在のバージョン: v1.04**

## 特徴

- 図形の90°回転・左右反転・上下反転、コピー/切り取り/貼り付け(Ctrl+C/X/V)
- Chromebookなど小さい画面でも右パネルがスクロールして全体が操作可能
- 四角形・円・直線・円弧・多角形・パス(自由曲線)・文字などの基本図形を作成
- 文字入力に対応(ゴシック体/明朝体/ゴシック体(極太)/ステンシル体)
- 16色の標準パレット + カスタムカラー
- グリッド表示・スナップ機能
- 部品ライブラリ(ねじ穴 M2/M3/M4、指継ぎタブ、差し込みスリット、曲げヒンジ)による自動生成
- 自動保存(ブラウザのlocalStorageに保存、外部送信なし)
- SVGファイルの書き出し(ダウンロード/クリップボードコピー/新しいタブ表示の3方式)
- アプリ内の「アプリについて」パネルから、現在開いているアプリ自身をHTMLファイルとしてその場でダウンロード可能

## 使い方

- **オンラインで使う**: GitHub Pages で公開している場合は、そのURLを開くだけで使えます。
- **ダウンロードして使う**: `laser_svg_editor_v1.04.html` をダウンロードし、ブラウザ(Chrome等)で開くだけで起動します。サーバーやビルド環境は不要です。アプリ内の「アプリについて」→「このアプリをHTMLファイルとしてダウンロード」ボタンから、開いているページ自身を保存することもできます。

使い方の詳しい説明は、同梱の `レーザーカットデザイナー_使い方ガイド_v1.04.pdf` (中学生向け) をご覧ください。

## ファイル構成とバージョン管理

- `index.html` — GitHub Pagesで公開するためのメインファイル(Pagesの仕様上、必ずこの名前にする必要があります)。中身は最新バージョンの `laser_svg_editor_v*.html` と同じです。
- `laser_svg_editor_v1.04.html` — ダウンロード配布用のファイル。ファイル名にバージョン番号を含めることで、どの版かひと目でわかるようにしています。

今後アプリを更新する際は、
1. アプリ内の `APP_VERSION` 定数(スクリプト冒頭)の値を上げる
2. 配布用ファイル名を `laser_svg_editor_v1.05.html` のように新しいバージョン番号へ変更する
3. `index.html` もあわせて同じ内容に更新する

という流れで、ファイル名・アプリ内表示(右上のバージョン表示、アプリについてパネル)のバージョン番号を一致させます。

## サンプルデータ

`sample_data/` フォルダに、アプリの「開く」ボタンで読み込める見本のSVGファイルがあります(板厚3mm用)。

- `sample1_box.svg` — 組み立て式の箱(ふたなし、外寸 90×70×50mm、指継ぎ接合)
- `sample2_keychain.svg` — キーホルダー3種(角丸長方形・円・六角形)
- `sample3_tree.svg` — スリットで十字に組み合わせるツリー

赤線＝切断、青線＝彫刻の例です。実際に使う色は、お使いのレーザーカッターの設定に合わせてください。

## 外部通信・データの扱いについて

このアプリはHTMLファイル1個で動作し、外部ライブラリ・アクセス解析・広告は一切使用していません。作成したデータは端末のブラウザ内にのみ自動保存され、外部に送信されることはありません。詳細はアプリ内の「アプリについて」画面でも確認できます。
