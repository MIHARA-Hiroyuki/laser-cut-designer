# レーザーカットデザイナー

レーザーカッターで加工するためのデータ(SVG)を、ブラウザだけで作成できる単一HTMLファイルの描画ツールです。インターネット接続や外部ライブラリ、インストール作業は一切不要で、ファイルを1つダウンロードして開くだけで使えます。学校のChromebookなど、管理が厳しい端末でも動作するように作られています。

## 特徴

- 四角形・円・直線・円弧・多角形・パス(自由曲線)・文字などの基本図形を作成
- 文字入力に対応(ゴシック体/明朝体/ゴシック体(極太)/ステンシル体)
- 16色の標準パレット + カスタムカラー
- グリッド表示・スナップ機能
- 部品ライブラリ(ねじ穴 M2/M3/M4、指継ぎタブ、差し込みスリット、曲げヒンジ)による自動生成
- 自動保存(ブラウザのlocalStorageに保存、外部送信なし)
- SVGファイルの書き出し(ダウンロード/クリップボードコピー/新しいタブ表示の3方式)

## 使い方

`laser_svg_editor.html` をダウンロードし、ブラウザ(Chrome等)で開くだけで起動します。サーバーやビルド環境は不要です。

使い方の詳しい説明は、同梱の `レーザーカットデザイナー_使い方ガイド.pdf` (中学生向け) をご覧ください。

## 外部通信・データの扱いについて

このアプリはHTMLファイル1個で動作し、外部ライブラリ・アクセス解析・広告は一切使用していません。作成したデータは端末のブラウザ内にのみ自動保存され、外部に送信されることはありません。詳細はアプリ内の「アプリについて」画面でも確認できます。
